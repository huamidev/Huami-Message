# 视觉风格：浅色版（TIM 那种感觉）

> **这是一次刻意的风格改向。**
> 原来的方案是「深色 + 流动极光 + 毛玻璃」（Apple Music 那种）。
> 现在改成「浅色 + 白卡片 + 一个明快的蓝」—— 也就是 TIM 那种干净、以内容为主的界面。
>
> 旧的那套代码没有删掉，它在 git 历史里（commit `2edd74c`）。

---

## 一、为什么这次改动只花了很少的功夫

因为从第 0 步开始，所有颜色和圆角就**只在 `Design/Theme.swift` 里定义**。
界面代码从来不写死颜色，只引用 `Theme.accent` 这样的名字。

所以"换配色"这件事变成了：**改一个文件 + 把几处早期硬编码的 `.white` 清掉**。

> 这正是当初把设计收进一个文件的目的。
> 如果颜色散落在二十个界面文件里，这次改动会变成一周的返工。

### 顺便说：哪些"白色"是必须保留的

清理 `.white` 的时候不能一刀切。有一类白色是**对的**：

- 蓝色气泡上的字
- 蓝色按钮上的字
- 未读红点里的数字
- 彩色头像上的首字

这些是"印在深色/彩色底上的字"，永远是白的。
真正要改的是"**印在白卡片上的字**"——那些必须变成深灰。

## 二、设计规则（想改风格照着这几条改）

### 1. 层次靠"白和灰的对比"，不靠模糊和发光

| 用途 | 颜色 | 说明 |
|---|---|---|
| 页面底色 | `#F2F3F5` | 很浅的灰。**不能是纯白**——纯白会让白卡片陷进去，看不出层次 |
| 卡片 / 列表项 | `#FFFFFF` | 白 |
| 输入框等次级面 | `#F7F8FA` | 比卡片"陷下去"一点 |
| 分隔线 | `#E8E9EB` | 极淡，但少了界面会糊成一片 |

### 2. 一个主色，用得越省越有分量

`#12B7F5`（TIM 那种明快蓝）。**只用在需要被看见的地方**：
按钮、未读红点、自己的气泡、可点的文字。

满屏都是蓝就变成廉价了。

### 3. 文字分三级，这个比换字体影响大

| 级别 | 颜色 | 用在哪 |
|---|---|---|
| 一级 `textPrimary` | `#1A1A1A` | 标题、消息正文 |
| 二级 `textSecondary` | `#5A5F66` | 说明、摘要、日期分隔 |
| 三级 `textTertiary` | `#9AA0A6` | 时间戳、占位提示 |

### 4. 阴影用得越省，界面越干净

只有**真正浮在内容之上的东西**才给阴影（输入栏）。
每个卡片都加阴影 = 每个元素都在抢注意力 = 廉价感。

阴影本身也要"大而淡"（`radius: 14, opacity: 0.07`）。
小而黑的阴影看起来像描边，很脏。

### 5. 头像用圆角方形，不是圆形

TIM / QQ 的头像是圆角方形。这个细节一眼就能看出"像不像"。
圆角取边长的 26%。

## 三、色板（直接抄）

```
主色        #12B7F5     自己的气泡 #12A9E8
主色浅      #E6F5FD     警告      #F5A623
青绿        #00BFA5     危险      #F5453D

页面底色    #F2F3F5     卡片      #FFFFFF     次级面 #F7F8FA
分隔线      #E8E9EB

文字一级    #1A1A1A     二级      #5A5F66     三级   #9AA0A6
```

在代码里用 `Color(hex: 0x12B7F5)` 这样写 —— 跟取色器上的数字一一对应，
不用心算除以 255，也不会抄错。

## 四、这次改动顺带修的两个视觉问题

**① 日期分隔条在浅色底上几乎看不见。**
它原来是毛玻璃胶囊 —— 靠背后的彩色光斑才显出来。
换成浅色之后没东西可透，就变成"灰底上的灰字"了。
改成实色浅灰胶囊 + 深一点的灰字。

**② 「我」页最后一张卡片被悬浮标签栏压住。**
底部留白从 72 加到 96。小事，但"最后一行看不见"是一眼就能察觉的毛病。
