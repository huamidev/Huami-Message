# 「军师」→ 聊天页内的「小助手」

> **这是一次产品结构上的修正。**
> 原本「AI 好友」是底部的一个独立 Tab（叫「军师」）。
> 现在它变成聊天页里一个悬浮的小按钮，点开就已经看得见你正在聊的那段对话。
>
> 底部 Tab 从 3 个变成 2 个：**「消息 / 我」**。

---

## 一、为什么原来的做法是错的

独立 Tab 的用法是这样的：

```
想问问助手怎么回  →  退出聊天  →  切到「军师」Tab
                  →  把对方的话复制出来、粘进去  →  点"帮我分析"
                  →  看建议  →  复制建议  →  切回聊天  →  粘贴  →  发送
```

**中间有四次"复制粘贴 + 切页面"。**

而这个助手的职责是"看懂对方说的话，帮你想怎么回" ——
它天生就该待在**对话发生的那个界面**里。让用户手动搬运聊天内容，
等于把机器该干的活推给了人。

现在：

```
想问问助手怎么回  →  点聊天页右下角「小助手」  →  点"帮我看看怎么回"
                  →  看分析 + 建议  →  点"用这个"（自动填进输入框）
```

**零次复制粘贴。**

> **通用经验：一个功能该放在哪里，取决于"用它的那一刻，用户的眼睛和手在哪"。**
> 如果用户为了用它必须先离开当前情境，那这个位置就是错的 —— 哪怕它看起来更"显眼"。

## 二、隐私：这是一次重要的变化，必须说清楚

### 润色（不变）

输入框左边那个 ✨，**只发送你正在打的那一句话**，从不读聊天记录。
这条原则没变过，界面上也一直写着。

### 小助手（新增，需要读对话）

它要分析"对方这句话什么意思"，就**必须看得到对话**。这是功能本身决定的，
没法回避。所以守两条底线：

1. **必须用户主动点两次**才会构造并发送上下文
   （点开小助手 + 再点一次「帮我看看怎么回」）。
   **绝不在后台偷偷读取。**
2. **发送前把"要发哪一段"原样显示出来** ——
   界面上直接列出"你和林一最近 5 条消息"，并把对方最后那句话贴出来。
   用户一眼就能确认"对，就是这一段"，而不是笼统地相信我们。

这是「**知情同意**」，不是「**默认同意**」。这两者差别很大。

### 只发必要的部分

上下文**最多取最近 10 条**（`AssistantContext.recentLimit`）。

限制条数不是为了省流量，是**为了少发一点隐私**：
判断"对方这句话什么意思"根本用不着三个月的聊天记录。
能少发就少发 —— 这是处理别人聊天内容时该有的自觉。

### 「我」页的隐私说明也跟着改了

新增一条「小助手会看到什么」，写清了上面这些。
**隐私承诺必须写在用户看得见的地方** —— 藏在设置深处的承诺等于没有。

## 三、一个技术设计：分析和建议必须分开

助手吐出来的东西分成两种：

```swift
enum AssistantEvent {
    case analysis(String)        // 分析文字，一个字一个字地流式吐出来
    case suggestions([String])   // 可回复的建议，一次给全
}
```

**为什么不干脆吐一大段文字？**

因为"建议"后面要挂一个「用这个」按钮 —— 它必须是**独立的数据**。
如果分析和建议混在一段文字里，界面就得靠解析字符串去把建议拆出来，
那种代码又脆又难维护：**AI 少打一个换行，功能就坏了。**

分开之后：
- 分析 = 一段文字，适合"长"出来（流式）
- 建议 = 一个字符串数组，每条自带一个按钮

以后换成真的 DeepSeek，让它先输出分析、再输出一个 JSON 数组就够了，
**界面一行都不用改**。

## 四、为什么按钮上要写字

输入框左边已经有一个 ✨（润色）。如果小助手也用一个小图标、还挨得很近，
用户一定会搞混 —— 而这两个功能完全不同：

| | 润色 ✨ | 小助手 |
|---|---|---|
| 干什么 | 改**你正在打的这一句话** | 帮你想**整件事该怎么办** |
| 看什么 | 只看那一句话 | 看最近 10 条对话 |
| 什么时候用 | 打完字、发送前 | 不知道该怎么回的时候 |

所以小助手做成了**带「小助手」三个字的小胶囊**。
多写三个字，歧义就没了 —— 这个代价值得。

## 六、还没做的

- **起草**（"帮我写一条道歉/请假的消息"）：现在只做"帮你回"。
  要做的话就是在小助手面板里加第二个按钮，接口已经支持。
- **多轮追问**：现在是一次问答。多轮要等真 AI 接上再说。
- **语音/图片消息的引用**：现在只会发纯文字。
