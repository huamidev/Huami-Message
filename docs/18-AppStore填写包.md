### 年龄分级

我们 App 里有**用户生成内容**（聊天消息）和 **AI 生成内容**，而且**没有年龄验证**。
苹果新版分级是 4+ / 9+ / 13+ / 16+ / 18+。

**建议选最严的那一档。** 理由：

- 分级填松了，审核发现会要求重新提交，白白多等一轮
- 分级填严了没有任何代价（朋友测试不看这个）

问卷里这几项要如实勾选：

| 问题 | 答 |
|---|---|
| 用户生成内容 | **是** |
| 用户可以互相交流 | **是** |
| 有举报机制 | **是** |
| 有拉黑机制 | **是**（这是苹果明确要求的配套措施，我们都有） |
| 包含 AI 生成内容 | **是** |

## 二、隐私申报（最重要的一节）

在 App Store Connect 的「App 隐私」里填。**逐项对照下面的表。**

### 我们实际收集了什么

| 苹果的分类 | 具体是什么 | 关联到你？ | 用途 | 用于追踪？ |
|---|---|---|---|---|
| 联系信息 → **电子邮件地址** | 注册用的邮箱 | ✅ 是 | App 功能 | ❌ 否 |
| 联系信息 → **姓名** | 昵称（默认取邮箱 @ 前面那段） | ✅ 是 | App 功能 | ❌ 否 |
| 用户内容 → **其他用户内容** | 你发的聊天消息 | ✅ 是 | App 功能 | ❌ 否 |
| 标识符 → **用户 ID** | 账号内部编号 | ✅ 是 | App 功能 | ❌ 否 |

**其余全部选「不收集」**：位置、通讯录、健康、财务、浏览记录、搜索历史、
购买记录、使用数据、诊断、广告数据……一个都没有。

### 为什么不申报"用于追踪"

因为我们**真的不追踪**：

- 没有接任何广告 SDK
- 没有接任何第三方统计 SDK
- 没有 IDFA（广告标识符），所以也不会弹「允许追踪」那个框
- 不跨 App / 跨网站关联你的行为

### 一个需要你知道的判断

消息内容会**发给 DeepSeek**（AI 服务商）处理——但只在你主动点润色或小助手的时候。

苹果的规则是：**代表你处理数据的服务商，算"你收集"，不算"分享给第三方"**。
所以我们按"收集"申报，不勾"与第三方共享"。

> 这条是我的判断，不是法律意见。如果你以后想更保守，可以在
> "与第三方共享"里也勾上——代价是用户会看到一个更吓人的提示。
>
> **重要的是：不管怎么申报，我们的隐私政策里已经如实写了这件事**（第 2 节）。
> 申报和政策一致，就不会有问题。

### 测试说明（What to Test）

```
请重点试这几件事，遇到任何别扭的地方都告诉我：

1. 打开 App 是不是立刻就能操作？会不会有等待或空白？
2. 发一条消息，点输入框旁边的 ✨ —— 三个润色版本是不是都能用？
```

## 五、隐私政策网址怎么发布

苹果要求隐私政策必须有一个**公开可访问的网址**（不能只在 App 里）。

页面我已经生成好了：`docs/legal/privacy-policy.html`。

### 发布步骤

1. 把项目推到 GitHub（如果还没有仓库，建一个私有的也行）
   > GitHub Pages 的免费额度对公开仓库才免费，私有仓库也能用 Pages，
   > 但有的账号类型有限制 —— 遇到问题跟我说。
2. 仓库 → **Settings** → 左侧 **Pages**
3. **Source** 选 `Deploy from a branch`
4. **Branch** 选 `main`，目录选 **`/docs`**
5. 点 **Save**，等 1-2 分钟
6. 网址就是：`https://你的用户名.github.io/仓库名/legal/privacy-policy.html`

验证一下：用手机浏览器打开这个网址，**能正常看到内容**再填进 App Store Connect。

> 改了条款内容之后，重新跑一次 `python3 tools/build-legal-html.py`，
> 网页版会自动和 App 内的文字保持一致。
