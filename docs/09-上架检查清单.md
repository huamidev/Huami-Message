## 二、必须你先操作的（我做不了）

这些都需要你的账号或身份信息，**也是目前唯一的阻塞项**。

### 1. Apple Developer Program（最关键，等最久）

- 费用 **$99/年**（中国区 ¥688/年）
- 个人身份注册即可。审核通常 24-48 小时，有时更久
- **没有它就不能用 TestFlight** —— 这是整个项目里等待时间最长的一环
- 注意：个人账号会把你的**法定姓名**显示在 App Store 开发者栏

> 你 Mac 上已经有一张开发证书（`Apple Development: 8619801879711`），
> 说明你登录过 Apple ID。但那**可能只是免费的"个人团队"** ——
> 免费账号能装到自己手机上（7 天失效），**不能**用 TestFlight。
> 所以请确认一下：你在 App Store Connect 里能创建 App 吗？

### 2. 注册 Supabase（后端）

- 免费，邮箱注册即可
- 需要你操作，我会在旁边一步步给指引

### 3. 注册 DeepSeek 开放平台（AI）

- 充几块钱就够测很久
- **API Key 绝对不能放进 App**，会走 Supabase 云函数中转（这一步我来做）

### 4. 发布隐私政策页面

- 页面已经生成好了：`docs/legal/privacy-policy.html` 和 `terms-of-service.html`
- 你在 GitHub 仓库设置里把 **Pages 的来源选成 `/docs` 目录**即可
- 网址会是 `https://<你的用户名>.github.io/<仓库名>/legal/privacy-policy.html`
- 这个网址要填进 App Store Connect 的「隐私政策 URL」

## 四、TestFlight 怎么发（等你账号好了之后）

1. Xcode 里选中「Any iOS Device (arm64)」，`Product → Archive`
2. 弹出窗口里选 `Distribute App → App Store Connect → Upload`
3. 等 10-30 分钟处理完，App Store Connect 里会出现这个构建
4. **内部测试员**（最多 100 人，你自己的 Apple ID 就算）：**不需要审核**，加上就能装
5. **外部测试员**（最多 10000 人）：需要 Beta App Review，通常 1-2 天

> 建议路径：先用内部测试员（你自己 + 1 个朋友）验证 → 再开外部测试。
> 每个构建**有效期 90 天**，过期要重传。

### 需要准备的审核物料

- [ ] 隐私政策 URL（见上面第 4 条）
- [ ] 一个可用的测试账号 —— **我们的 App 有登录功能，必须给审核员一个能直接登录的账号**，否则必被拒
- [ ] 测试说明（Test Information）：告诉审核员这个 App 是干什么的、怎么测
- [ ] 反馈邮箱
