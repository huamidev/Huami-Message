## P1 · 语音听不见

已经加了能分辨层级的日志（`1945f95`）：

```
语音录制：7xxx 字节 / 2.3 秒
语音播放：7xxx 字节，时长 2.3s，play()=true，音量 1.00，
         会话类型 playback，输出 Speaker
```

- **字节数只有几百** → 录音本身是空的，问题在录
- **字节正常但 `play()=false`** → 播放器起不来
- **都正常却听不见** → 输出路由 / 静音开关

顺带检查：**手机侧面的静音开关**。
`.playback` 类型会无视静音开关，但如果那句设置失败退回默认类型，就会没声。
