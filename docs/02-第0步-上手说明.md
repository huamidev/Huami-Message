## 二、为什么先做界面，而不是先接后端

这是我在你的原计划前面插了一步，理由再说一遍：

1. **毛玻璃不是"最后刷的一层漆"，它是布局方式。**
   `.ultraThinMaterial` 只有在"有内容从它底下滚过去"的层级里才好看。
   等 4 个功能都做完再改层级，等于重写。
2. **假数据阶段能 100% 专注手感**，改一行看一眼效果。这是最容易建立信心、
   也最容易学明白的阶段。
3. 如果一上来就搭后端，你要先注册服务、配数据库、学网络请求，
   可能两天看不到任何画面，很容易放弃。
4. **但最多花 2-3 天。** 真正会卡住你的是后端和审核，UI 不是风险点。

## 三、你要动手做什么

### 1. 打开工程

在「终端」里执行：

```bash
open "/Users/huami/Developer/Huami Message/Huami Message.xcodeproj"
```

（或者直接双击 `Huami Message.xcodeproj` 文件。）

### 2. 按 ⌘R 跑起来

Xcode 顶部左侧有个设备选择框，选 **iPhone 17** 之类的模拟器，然后按 `⌘R`。
大约十几秒后，模拟器里就会出现这个 App。

### 3. 试着点一点，重点感受这几处

- 进「消息」→ 点**林一** → 在输入框里打几个字 → 点左边的 ✨ 按钮
- 看**三个版本同时一个字一个字地长出来**
- 点「用这个」，文字会填回输入框（**不会自动发出去**，这是故意的）
- 然后点发送，看消息"啵"地弹出来
- 等 2.5 秒，林一会自动回你一句（这是在模拟"实时收消息"）
- 在聊天页点右下角的「小助手」→ 再点「帮我看看怎么回」

### 4. 想装到自己 iPhone 上

1. 用数据线连上 iPhone，手机上会弹出"信任此电脑"，点信任
2. Xcode 顶部的设备框里选中你的 iPhone
3. 按 `⌘R`
4. 手机上会提示"不受信任的开发者"，去 **设置 → 通用 → VPN与设备管理** 里信任一下

> 免费 Apple 账号装的 App **7 天就失效**，要重新装一次。
> 付费开发者账号（$99/年）是一年，而且才能用 TestFlight。

### 为什么要有 `Services` 这一层

界面（View）永远只跟 `ChatService` 这个**协议**说话，
永远不知道数据到底是假数据还是从服务器来的。

以后写 `SupabaseChatService` 替换 `MockChatService` 时，
**所有界面代码一行都不用改**。

打个比方：这份协议就是墙上的插座标准。今天插的是"调试电源"，
明天换成"市电"，墙上的插孔形状不变，所以电器（界面）不用换。

## 五、我在这一步踩的两个坑（值得你记住）

这两个坑我都是**用截图和取像素值发现的**，不是猜的。

### 坑 1：装饰元素把整个界面撑宽了

我把极光背景写成 `ZStack { 底色; 光斑 }`，而光斑是 520×520 的固定尺寸。
SwiftUI 的 ZStack 尺寸取"所有子视图里最大的那个"，于是背景被撑成 520 宽，
而 iPhone 屏幕只有 402 宽 —— 结果导航栏标题和卡片全被撑宽、左右裁掉，
背景上下还变成死黑。

**教训：装饰性的东西绝对不能参与布局计算。**
用 `overlay` 把装饰"挂"上去，让一个可伸缩的底色来决定尺寸。

### 坑 2：往系统容器"后面"塞东西没用

修完上面那个之后，背景还是纯黑。我写了个小工具取像素，
量出该是 `#0F1221` 的地方是 `#000000`。

原因是 `TabView` / `NavigationStack` 这些系统容器会给自己画一层不透明背景，
深色模式下正好是纯黑，把放在它们后面的背景整个盖住了。

**教训：往系统容器「后面」塞东西通常无效，要往「里面」塞。**
所以极光背景现在放在每个页面内部（`GlassPage`）。

## 六、调试开关（方便你自己测试）

带启动参数可以直接跳到某个页面，不用手点：

```bash
# 直接进会话并打开小助手
xcrun simctl launch booted com.huamidev.HuamiMessage -openChat 1 -openAssistant 1

# 直接进第一个会话
xcrun simctl launch booted com.huamidev.HuamiMessage -openChat 1

# 直接进会话 + 自动打开润色面板
xcrun simctl launch booted com.huamidev.HuamiMessage -openChat 1 -openPolish 1
```

这些开关全部集中在 [DevFlags.swift](../Huami%20Message/Support/DevFlags.swift)，
正常启动时**全部关闭**，不影响你自己用、也不影响朋友用。
